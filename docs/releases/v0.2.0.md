# BrainWays v0.2.0 — Brain networks & cognitive systems

This release introduces two new data layers that sit *above* the anatomical
atlas: **large-scale brain networks** (resting-state) and **cognitive systems**
(higher-order constructs). Both are joined to the existing anatomy by stable
structure IDs, so they layer onto the same 3D brain without touching any saved
user data.

## Brain networks (7)

The Yeo et al. (2011) seven-network parcellation is now explorable as a
dedicated mode:

- **Visual**, **Somatomotor**, **Dorsal attention**, **Ventral attention**,
  **Limbic**, **Frontoparietal**, and **Default-mode** networks — plus a
  **full-brain network map** overlay.
- Each network has an info card with key structures, supporting tracts,
  function, associated states, experimental paradigms, clinical alterations,
  and cited references.

## Cognitive systems (12)

A new layer of overlapping higher-order constructs that recruit the
resting-state networks:

- **Working memory**, **Attention**, **Cognitive control**, **Self-referential
  processing**, **Theory of mind**, **Episodic memory**, **Semantic memory**,
  **Emotion**, **Value-based decision-making**, **Interoception**,
  **Metacognition**, and **Spatial cognition & navigation**.
- Each system carries a summary, its recruited networks, constituent
  structures, components/stages, and an info card covering function, states,
  paradigms, disorders, and primary-literature citations.

## Explore

- Three-way mode switch in the left panel: **anatomy · networks · cognition**
  (panel widened to fit).
- Selecting a network or cognitive system highlights its structures on the
  model in that system's color.

## Study

- Guided lessons for all cognitive systems, with staged narration and static
  structure highlighting.
- Lessons now show `N stages · N questions` and link into a dedicated quiz on
  completion.

## Quiz

- **36 new multiple-choice questions** across the cognitive systems (3 per
  system), with cited explanations.
- The assessment dropdown now separates **Functional systems** and
  **Cognitive systems**, and cognitive questions participate in the
  "All systems" pool.

## Review

- Spaced-repetition cards now surface which cognitive systems (and networks) a
  structure participates in.

## Under the hood

- Two new hand-authored data files (`networks.json`, `cognitive-systems.json`)
  with reverse-index loaders, mirroring the existing `atlas.json` /
  `systems.json` split.
- `check:data` now validates network, cognitive-system, and cognitive-question
  references.
- Added Playwright smoke tests for the networks and study flow.
